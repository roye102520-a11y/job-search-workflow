- 测试编写期间修正了两处测试假设：原文对话框关闭后再检查分析标题焦点的时机不成立；7 天分析工具原本要求编号 JD。最终测试分别验证正确时机，以及未编号报错后输入恢复。这两项不记为产品 Bug 修复。
