# UI 设计与前后差异

> 历史记录：本文记录 V2 改版交付时的界面。2026-10-15 用户确认恢复改版前外观；当前导航、布局与截图见 [UI 恢复记录](../ui-restoration/README.md)。V2 数据与安全修复保留。

采用温暖中性色、单一深绿强调色、系统字体与原生表单。减少大标题和重复卡片，主要行动至少 44px；键盘焦点、跳转正文、错误/空/加载状态明确；小字号提升到 12px，按内容堆叠响应式布局。

| 原体验 | V2 |
|---|---|
| 首页展示功能总览与大统计 | 首页按档案状态显示上传/复核/分析行动 |
| 目标设置藏在投递页 | 我的档案中设置目标；首页显示当前目标 |
| 作品集被列为核心第二步 | 目标成为第二步；作品展示可选 |
| 六个平级入口 | 五个入口；面试归入求职进度 |
| 两列 JD 输入与生成预览 | 宽屏 JD / 证据与差距 / 选材与材料三列；窄屏顺序堆叠 |
| 只能看到最终选材 | 可展开全部候选、原表述、来源、未选原因，调整优先项目 |
| 准备与 ready 合并 | 六阶段看板；ready 明确为可人工审核 |
| 预览强调产品叙事 | 首屏明确合成、能体验什么、完整功能在哪、怎么开始 |

公开页提供五种合成使用场景和三份预设岗位，明确不运行本地算法、不接收真实简历。本地首页只展示当前案例文件中的数量，档案完整度是提供字段数 / 5，不是能力或可信度评分。

设计来源和令牌见项目 PRODUCT.md、DESIGN.md、.impeccable/design.json。Impeccable 上下文引擎因安装目录/网络不可用未运行，遵循已读取的 Operate 与 craft floor；不声称通过其检测器。
