## 原页面信息架构

`总览 → 素材与作品集 → JD 简历 → 投递进度 → 面试复盘 → 个人网站`。首页为宣传句、流程、方向计数与功能卡片；目标设置藏在投递页；作品展示被放进必须先经过的第二步。首次用户和已有事实库用户看到同一个生成入口。

## 最高影响问题

1. 首次进入缺乏依数据状态变化的下一步；缺少事实库也直接引导生成。
2. 硬条件理由写死专业；相邻实践和不完整经历可能产生错误结论。
3. 固定条数/项目数截断，没有全部候选与未选原因，重要 OCR 项可能漏选。
4. BOSS 的双休与周末加班冲突、实际地点、重复条件冲突不够清楚。
5. 静态预览、准备材料、真实投递与已核验岗位需要更明确的边界；缓存也必须只保存外壳。
