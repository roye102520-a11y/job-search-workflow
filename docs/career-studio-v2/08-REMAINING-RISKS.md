# 剩余风险与人工验证

1. **线上未验收**：Vercel 访问超时；远端 HEAD 受本机代理影响不能验证。当前分支以现有本地源码为基点，没有生产部署。
2. **真实性不能由哈希证明**：来源摘要、ID 与候选人隔离可检查；数字真实、个人贡献/团队成果、原文与缓存的语义一致性仍需本人/Codex 逐项核对。
3. **规则覆盖有限**：复杂否定、英文复合要求、行业经验和多地点文本不能保证正确；需人工确认主次方向和硬门槛。规则分不是概率。
4. **老版本摘要限制**：旧 selection 不含完整缓存摘要，只能校验原有源文件摘要；仍可查看/恢复，但建议重生成再外发。没有重写或删除旧档。
5. **旧台账与事件质量**：手工编辑的历史记录可能缺回执、存在阶段别名冲突或无日期。本轮不修写真实历史；确认投递需要逐条核验来源。
6. **完整性字段**：只在本人确认后设 complete=true；旧档未设视为未知完整性，不能以记录不足判明确不满足。
7. **真实职位时效**：导入数据只能证明导入时声称的条件。账号状态、链接在线有效性和招聘是否继续均未知，last_verified_at 保持空。
8. **工作年限精度**：目前按月计算，起止月份都包含；整年门槛需精确到天时必须人工复核。未来结束月份被截到当前月份，至今与其他异常格式可能进入待核实。
9. **用户理解测试**：五个浏览器场景只验证路径和状态，不证明真人一分钟内理解。需 5–8 位目标用户进行无引导计时测试。
10. **无障碍/跨浏览器**：本轮检查 Chromium 键盘入口与响应式；完整屏幕阅读器、Safari/iOS、Android、实际 PDF 视觉、扫描件 OCR 需人工验收。
11. **完整事实库的建立仍有人工步骤**：导入提取与事实确认分开，网页没有自动把未经确认的材料写入事实库。需要在 Codex 中综合核对；这是当前能力边界。
12. **公开部署权限**：生产部署、真实个人数据修改、真实外部投递均未执行，需单独批准。

这些是限制/推测风险，不列为已复现且已消除的 Bug。测试通过不等于招聘结果可预测，也不等于完整云端产品就绪。
