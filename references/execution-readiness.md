# 按需检查执行能力

只有任务进入导出、浏览器填写、邮件或同步阶段时才检查该项；不为单句简历修改增加环境巡检。

| 动作 | 验证什么 | 缺失时交付 |
|---|---|---|
| Word / PDF | 可用文档工具、字体、渲染与提取能力；检查真实输出 | 可编辑文本，明确尚未导出 |
| 岗位读取 | 页面可访问、公司/ATS 关联、岗位当前有效性 | 用户提供 JD 的分析，标明有效性未知 |
| 网申填写 | 能读取页面并回读字段；用户已登录或需要接手；当前授权范围 | 字段—已确认答案清单与断点 |
| 邮件 | 能创建草稿还是能发送；附件能力；消息回执语义；真实收件人 | 邮件文本与附件清单，标记未发送 |
| 飞书 | 可访问目标表、字段映射、是否能查重更新 | 本地 CSV，标记未同步 |

区分“发现工具”“连接/登录可用”“真实流程已验收”。不能只因工具名称出现在列表就声称已接通。只做当前任务需要的最小检查，不为检测而发送测试邮件、上传个人资料或创建外部记录。

## 网站字段经验与个人答案分开

只有实际遇到重复表单才在案例中建立 `portal-notes/<domain>.md`，保存可见标签、字段类型、日期格式、字段依赖、最后验证日期和本次失效项；个人值仍只来自 profile/答案库。网站 UI 变化时重新读取，不沿用失效定位。记录不得含密码、Cookie、令牌、验证码或个人真实答案。此文件是操作经验，不是通用 ATS 适配器实现。
