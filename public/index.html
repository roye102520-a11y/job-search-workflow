公开展示，
本地完成实际工作。

这个页面展示工作方式。完整工作台在你的电脑运行，读取由你保管的案例材料，生成对应 JD 的审阅稿。

开始使用 Skill

在本地安装依赖，准备案例目录并启动服务，然后打开 http://127.0.0.1:8765。首次使用导入材料并核对事实；已有事实库可直接分析 JD。

python3 -m pip install -r requirements.txt
mkdir -p /path/to/your-case
python3 scripts/resume_server.py \
  --case /path/to/your-case \
  --port 8765

本公开预览不连接本机 API，不读取个人简历，也不上传投递记录。跨设备使用完整功能时，需由你自行配置安全的服务与数据存储。

本地工作台还可以做什么？

导入 PDF、Word、Markdown 或文字后，核对原文、个人贡献与冲突；没有简历也可以先在 Codex 中记录一段经历。作品集与网站草稿可以按需跳过。

申请按待研究、待准备、可人工审核、已投递、面试中、已结束记录。材料生成不会视为已投递，必须有真实回执或本人确认。

BOSS 离线筛选区分符合已知条件、待核实、明确排除和重复记录；离线数据无法证明岗位仍在招聘。练习和面试复盘不会自动成为职业事实。
