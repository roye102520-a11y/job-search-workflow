了解完整功能

完整功能在哪里使用？

在电脑下载项目，安装依赖，指定案例目录并启动本地工作台。首次使用先建立空目录，导入材料后在 Codex 中核对事实。

python3 -m pip install -r requirements.txt
mkdir -p /path/to/your-case
python3 scripts/resume_server.py --case /path/to/your-case --port 8765

然后打开 http://127.0.0.1:8765。已有事实库可直接分析 JD；只改一份简历时，从「岗位与简历」进入。
